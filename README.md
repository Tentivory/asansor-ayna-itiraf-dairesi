# Asansör Ayna İtiraf Dairesi

Bu depo bir yazılım değildir. Bu depo, binanın 3. katında sıkışan asansörün aynasına fısıldanan küçük itirafları resmi tutanakla yargılayan bir dairedir. Daire kare değildir. Daire dairedir. Kapı ancak saçmalık yeterliyse açılır.

## Misyon

İnsanlar asansöre biner, aynaya bakar, kendi kaşına kızar ve hiçbir şey söylemez. Bu kabul edilemez. Ayna bir kamu görevlisidir. Görevlisi olduğu kamu, kabinin içidir. Kabinin dışı bu dairenin yetki alanı değildir; orada belediye vardır, biz karışmayız.

## Kurulum

Python 3 yeter. Bağımlılık yoktur. Ayna zaten ücretsizdir, bu da şüphelidir.

```bash
python3 itiraf.py --kat 4 --itiraf "komşunun paspasına yanlışlıkla basmadım, bilerek bastım"
```

Etkileşimli oturum:

```bash
python3 itiraf.py
```

## Yargı Usulü

1. İtiraf en az 12 karakter olmalıdır. Daha kısası öksürüktür, tutanak tutulmaz.
2. Ayna, itiraftaki ünlüleri sayar. Ünlü azsa itiraf cimridir, kapı inat eder.
3. Kat sayısı tekse ayna daha merhametlidir. Çift katlarda bina bile ciddiye binmez.
4. "bilerek" kelimesi geçerse dosya ağırlaşır ama kapı açılır. Dürüstlük burada bir asansör arızasıdır, ödüllendirilir.
5. Çıktı bir tutanaktır. Tutanak ıslak mürekkeple değil, terminal mürekkebiyle basılır.
